# zulu-sync

라이브 공연용 동기화 도구. 마스터가 음원/LTC 실행을 제어하면 모든 참여자 단말이 같은 시각에 동일한 위치에서 재생됩니다.

## 다운로드

- **Windows**: [zulu-sync_x64-setup.exe](https://github.com/zuluworks/zulu-sync/releases/latest/download/zulu-sync_x64-setup.exe)
- **macOS (Apple Silicon)**: [zulu-sync.dmg](https://github.com/zuluworks/zulu-sync/releases/latest/download/zulu-sync.dmg)
- **Android** (베타): Firebase App Distribution 초대 받은 사용자만 — 별도 안내

설치 후에는 앱이 자동으로 새 버전을 확인합니다.
